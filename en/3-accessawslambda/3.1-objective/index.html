Objective

Configuring Lambda@Edge to Add Security Headers for CloudFront

🔹 Step 1: Create a Lambda Function

  1. Go to AWS Lambda.
  2. Select Region: US East (N. Virginia) (us-east-1).

  1. Click Create function.
  2. Choose Author from scratch, then configure:
    • Function name: AddSecurityHeaders
    • Runtime: Node.js 18.x

🔹 Step 2: Add Handler Code to Lambda

After creating the function successfully, replace the default content with the following code:

"use strict";
export const handler = async (event) => {
  const response = event.Records[0].cf.response;
  const headers = response.headers;

  headers["strict-transport-security"] = [
    {
      key: "Strict-Transport-Security",
      value: "max-age=63072000; includeSubDomains; preload",
    },
  ];
  headers["content-security-policy"] = [
    { key: "Content-Security-Policy", value: "default-src 'self'" },
  ];
  headers["x-content-type-options"] = [
    { key: "X-Content-Type-Options", value: "nosniff" },
  ];
  headers["x-frame-options"] = [{ key: "X-Frame-Options", value: "DENY" }];
  headers["x-xss-protection"] = [
    { key: "X-XSS-Protection", value: "1; mode=block" },
  ];

  return response;
};

Click the Deploy (Ctrl + Shift + U) button to update the function.

Go to the Roles section

  • Look for the role named: LambdaEdgeSecurityRole

Select the Trust relationships tab → click Edit trust policy

Update the trust policy content

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "Service": [
                    "lambda.amazonaws.com",
                    "edgelambda.amazonaws.com"
                ]
            },
            "Action": "sts:AssumeRole"
        }
    ]
}

Version description: V1 → Publish

Step 3: Attach the Function to CloudFront

  1. Go to CloudFront → select the Distribution.

  2. Switch to the Behaviors tab, find the behavior /index.html → click Edit.

  1. In the Function association section:

    • Function type: Lambda@Edge

    • Function ARN:
      arn:aws:lambda:us-east-1:806361468439:function:AddSecurityHeaders:3

    • Click Save changes to finish.

In CloudFront → Select Distribution → go to the Origins tab → click Edit → then Create new OAI

Set the name: webbadmintonvideo.s3.us-east-1.amazonaws.com

Click Create
