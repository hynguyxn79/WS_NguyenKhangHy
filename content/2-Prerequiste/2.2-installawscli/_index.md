**Step 1**: Open Windows CMD as Administrator.

**Step 2**: Enter `choco install eksctl -y choco install awscli -y` to use **Chocolatey** to install **AWSCLI**.

  ![](/images/2.prerequisite/3.png)

If the result appears as above, it means **AWSCLI** has been successfully installed.
