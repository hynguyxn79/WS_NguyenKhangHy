**Bước 1**: Mở CMD của Windows dưới quyền Administrator

**Bước 2**: Nhập  `choco install eksctl -ychoco install awscli -y` để sử dụng **Chocolatey** để cài đặt **Awscli**.

  ![](/images/2.prerequisite/3.png)

Nếu kết quả như trên có nghĩa là đã cài dặt AWSCLI thành công.
