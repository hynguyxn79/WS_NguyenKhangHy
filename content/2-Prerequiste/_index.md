To use AWS services without relying on the Console for deployment, as well as to perform operations for creating data within the services, we need to install **AWSCLI**, **EKSCTL**, and **KubernetesCTL** to deploy from **Windows CMD**. This makes it easier to operate and simplifies the process of setting up data in the **AWS Console**.
